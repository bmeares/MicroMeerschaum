# Support independent Meerschaum deployments

MicroMeerschaum is a general-purpose, open-source framework. Its first release demonstrates a Pipe syncing between two independently configured nodes. A peer can be the destination for an offline site. A team can also connect its own sensor to an ordinary Meerschaum deployment through the receiver plugin.

The framework owns record identity, delivery, receipts and lineage. Downstream applications select sensors, configure links between nodes and contribute reusable improvements upstream as needs emerge. The release example and conformance tests belong in this repository so any team can run them. [Node-to-node release criteria](../peer-sync.md#initial-release-example)
